# 通灵（TongLing）

大模型共情智能开放测评平台的静态网站源码，包含公共数据集、测评框架、自有数据集与模型榜单页面。

## 本地预览

在仓库根目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## 安全说明

仓库不包含本地访问口令或线上反馈服务凭据。若需要启用相关功能，请使用本地配置或部署平台的环境变量，不要把敏感值提交到 Git。

## 部署

当前仓库只保存源码，未启用自动部署。确认公开范围和运行配置后，再单独配置 GitHub Pages。
